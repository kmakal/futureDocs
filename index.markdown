## Code Sections
Code sections make it clear when text should be interpreted as code. Common examples include using the command line, adding lines to scripts, or other typing tasks. Markdown includes methods to denote short and long pieces of code. 

HOW TO CREATE CODE SECTIONS IN MARKDOWN 

To insert a short piece of code:
1. Begin the code section in the text with a backtick mark `
2. Write the code phrase
3. Finish the section with a second backtick mark `
4. Result: `<p style="font-size:50px;">I am big</p>
`

To insert a multi-line piece of code
1. Start a new line with 3 backtick marks ```
2. On a new line, begin writing the liens of code
3. On a new line, finish th ecode block with three backlink marks ```

For example
```
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Sample Webpage</title>
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>This is a short snippet of <strong>HTML</strong> code containing a heading and a paragraph.</p>
    <a href="https://example.com">Visit Example.com</a>
</body>
</html>
```
